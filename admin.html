관리자 기능 준비 중

교회 전용 인증 서버와 저장 공간이 아직 연결되지 않았습니다.

현재 홈페이지는 정상적으로 운영됩니다. 이 화면은 보안을 위해 비밀번호 입력을 받지 않습니다. 별도의 Supabase 프로젝트를 준비하고 site-config.js를 설정해야 로그인 기능이 활성화됩니다.

관리자 로그인

교회 측에서 승인한 계정만 접근할 수 있습니다. 사용자 신규 가입 기능은 제공하지 않습니다.

주보·설교 게시 관리

공개 버튼을 켜고 저장하면 게시됩니다. 비공개 글에 올린 파일도 공개 저장소의 주소를 알면 열람할 수 있으므로, 교회 측에서 공개를 승인한 이미지·PDF만 업로드하세요. 관리자 권한은 서버의 접근 정책(RLS)으로 제한됩니다.

설교 동영상이 없어도 날짜·제목·본문·요약만으로 등록할 수 있습니다.

기존 첨부파일은 수정 시 아래 링크에서 확인할 수 있습니다. 파일을 새로 고르지 않으면 기존 파일은 유지됩니다.
